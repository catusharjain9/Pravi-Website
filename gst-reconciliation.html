GSTR-2B vs purchase register reconciliation

A practical review workpaper for finance teams: map the source columns, match supplier invoices, inspect exceptions and export a reviewable reconciliation report.

← Back to business tools

1Load source files

Upload the GSTR-2B Excel/CSV export and the purchase-register Excel/CSV export for the same GSTIN and tax period. The files stay in this browser session; there is no upload endpoint.

For a reliable match, use files for one GSTIN and one tax period. The tool uses supplier GSTIN + normalized invoice/document number, and optionally document type when mapped in both files. It does not determine ITC eligibility or replace the GST portal’s matching workflow.

2Confirm column mapping

Header names vary by accounting software. Auto-detected columns are only suggestions; verify them before matching. Fields marked optional are not used unless mapped.
