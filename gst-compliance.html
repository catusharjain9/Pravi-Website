How this area works

Start with the return period, source records and the mismatch.

GST work often depends on aligning sales and purchase records with portal data, understanding differences and documenting items that need review. The required workflow depends on the return period, transaction type and the status of the underlying records.

Potential scope

What this support can include.

The workflow depends on the return period, transaction facts, portal data and agreed responsibilities.

Registration and profile support

Document coordination for relevant GST registration, amendment or profile requirements.

Return preparation support

Prepare or coordinate the agreed GSTR-1, GSTR-3B or related return information, subject to review and authorisation.

Books-to-portal reconciliation

Compare accounting records with available GSTR-2A / GSTR-2B and identify differences requiring investigation.

Input tax credit review support

Prepare exception lists and supporting schedules for consideration against the applicable facts and rules.

Refund documentation

Organise transaction details and supporting evidence for a scoped refund application.

Notice / query preparation

Map the issue, information required and response timeline; representation is separately scoped where applicable.

PREPARATION CHECKLIST

  • Relevant GSTINs and periods (do not send full identifiers in the first enquiry)

Frequently asked questions

Before you proceed.

Do you guarantee a clean reconciliation?

No. Reconciliation identifies differences; resolving them depends on underlying records, supplier actions, eligibility and applicable law. Findings and assumptions should be documented.

Can PRAVI file on my behalf immediately?

Any filing, signing or authorised portal action requires an agreed scope, the required access/authorisation and appropriate review. An initial website enquiry does not create an engagement.

Make the GST issue easier to assess.

Identify the return period, whether the issue relates to sales or purchases, and the broad type of difference. Do not send sensitive records in the first message.
